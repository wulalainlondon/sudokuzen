# 《數獨俠客傳》產品開發企劃書

**專案代號**： Project Zen Neon
**版本**： v1.0 — 2026-03-29
**核心語彙**： 邏輯狩獵、維度打擊、視覺按摩、i14 Pro Vibe
**目標受眾**： 追求極致視覺體驗的科技愛好者、渴望邏輯成長的益智玩家

## 一、產品定位與核心願景

### 1.1 一句話定位

> **把數獨從填字遊戲，變成招式遊戲。**

### 1.2 品類定義

**結構辨識 × 招式施放（Structure Recognition × Skill Casting）**

本產品打破數獨「枯燥填字」的刻板印象，將其轉化為一款邏輯狩獵遊戲：

| 傳統數獨 | 數獨俠客傳 |
|----------|-----------|
| 玩家是「填字員」 | 玩家是「看穿結構、發動招式的俠客」 |
| 題目是「待解的空格」 | 題目是「具備稀有度的邏輯神獸」 |
| 技法是「腦中的知識」 | 技法是「可施放、可演出、可收集的招式」 |
| 難度是「給更少的線索」 | 難度是「出沒更稀有的結構」 |

### 1.3 為什麼這是一條新賽道

所有現有數獨 app 共享同一個前提：**技法是知識，玩家證明「知道」就行。**

本產品的前提是：**技法是技能，玩家必須「做出來」才算。**

這把數獨從「填空題」推進到有 skill ceiling 的表現型遊戲——一個被 speedrun、音遊、格鬥遊戲驗證過的巨大品類。

### 1.4 競爭態勢

| 競品 | 教學 | 技法數 | 招式施放 | 生態系統 |
|------|------|--------|---------|---------|
| Sudoku.com（Easybrain） | 無，提示=給答案 | 0 | 無 | 無 |
| Sudoku :)（Maple Media） | 無 | 0 | 無 | 無 |
| Enjoy Sudoku（Linhart） | 漸進提示 | ~15 | 無 | 無 |
| Good Sudoku（Zach Gage） | AI 教練 | ~12-15 | 無 | 無 |
| **數獨俠客傳** | **互動課程 + 演示動畫** | **40** | **有** | **有** |

Good Sudoku 教到 X-Wing 就停了。我們從 X-Wing 教到 Death Blossom。**這中間的 25 種技法，整個 App Store 沒有人在教，更沒有人做成可施放的招式。**

## 二、核心玩法循環（The Core Loop）

```
  ┌──────────────────────────────────────────┐
  │                                          │
  │    荒野 (The Wild)                        │
  │    遇到邏輯神獸 → 辨識結構 → 施放招式      │
  │         │                    │            │
  │         │ 失敗：神獸逃跑      │ 成功：      │
  │         │ 「此為鋒刃之形...」  │ 招式演出    │
  │         ▼                    │ EXP + 圖鑑  │
  │    秘笈 (The Dojo)           │            │
  │    學習技法 → 練習 → 開 buff   │            │
  │         │                    │            │
  │         └── 回到荒野 ─────────┘            │
  │              出沒率 +50% (30 min)          │
  └──────────────────────────────────────────┘
```

### 2.1 開局自動化：全候選戰場（Full Candidate Battlefield）

**機制**：進入關卡後，系統自動填入所有合法候選數。依照玩家選擇的戰場模式，自動消除基礎邏輯。

**目的**：消除無效勞動，讓玩家直接進入高級邏輯對決。

**三檔戰場模式**：

| 模式 | 行為 | 適合誰 |
|------|------|--------|
| **俠客模式**（預設） | 全候選 + 自動消除 Naked/Hidden Single | 新玩家、追求招式體驗 |
| **修士模式** | 全候選，不自動消除 | 中等玩家，想自己找 Single |
| **苦行模式** | 空棋盤，自己填候選 | 紙筆派硬核玩家 |

### 2.2 招式啟動系統（Skill Trigger System）

#### 操作流程

```
長按任意候選格 → 進入「選取態」（格子亮起脈衝光環）
  → 點選第二格（連線延伸，張力遞增）
  → 點選第三格
  → 點選第四格
  → 系統即時判定：結構是否成立
      ✓ 成立 → 招式名浮現 → 施放鍵亮起 → 按下施放
      ✗ 不成立 → 連線消散 / 提示修正方向
```

#### 施放演出時序（以 X-Wing 為例）

```
T+0.0s  四個錨點同時亮起金色
T+0.3s  兩條對角線同時射出，形成 X 交叉
T+0.5s  畫面凍結 0.5s — 招式名「鋒刃 · X-Wing」大字浮現
T+1.0s  交叉線沿行/列掃射 — 命中的候選逐一打上 ✕
T+1.8s  消除計數浮現 — 「×4 eliminated」
T+2.2s  歸位，字幕：「行列封鎖，四點歸一」
```

#### 失敗回饋分層

| 失敗類型 | 回饋 | 設計意圖 |
|---------|------|---------|
| 格位不構成任何技法 | 連線淡出消散 | 「不是這個」，無懲罰 |
| 接近某技法但差一格 | 連線閃爍 + 字幕「結構不完整」 | **教學機會**，引導修正 |
| 格位對但候選數字不匹配 | 連線變色 + 「候選不匹配」 | 引導觀察數字 |
| 完全亂選 | 靜默取消 | 避免挫敗感 |

### 2.3 字幕系統（Live Commentary）

全程「實況推理播報」，分三個階段：

| 階段 | 字幕示例 |
|------|---------|
| **選取中** | 「第 2 列與第 7 列，候選 9 各現兩處...」 |
| **施放中** | 「鋒刃成形 — 行列封鎖啟動」 |
| **施放後** | 「消除 4 個候選，剩餘路徑已收窄」 |

## 三、智力等級與生態系統（IQ Level & Ecology）

### 3.1 核心機制

將數獨技法的 **自然統計分布** 直接轉化為遊戲內的 **神獸出沒率**：

> 學術事實：X-Wing 自然出現率 0.8%
> → 遊戲機制：X-Wing 是稀有神獸，Lv.30+ 才解鎖出沒
> → 情感體驗：「我遇到 X-Wing 了！」— 奇遇感、稀缺感、成就感

### 3.2 等級與出沒率對照

| 玩家等級 | 可出沒的最高技法 | 稀有度體感 |
|---------|----------------|-----------|
| Lv.1-10 | Naked/Hidden Single, Locked Candidates | 95% 基礎怪，練習起手式 |
| Lv.11-20 | Naked/Hidden Pair, Naked Triple | 開始出現結構型邏輯 |
| Lv.21-30 | Unique Rectangle, Skyscraper | 偶遇中階形態 |
| Lv.31-40 | X-Wing (~0.8%), XY-Wing (~3%) | 稀有神獸開始出沒 |
| Lv.41-50 | Swordfish (~0.2%), Coloring (~8%) | 需要秘笈修煉才能應對 |
| Lv.51-60 | Jellyfish (~0.01%), ALS-XZ | 傳說級，萬題一遇 |
| Lv.61-70 | AIC, Forcing Chain | 深淵級，需要鏈式思維 |
| Lv.71-80 | ALS-Chain, Sue de Coq | 神話級 |
| Lv.80+ | Death Blossom, Exocet | 終極形態 |

### 3.3 自然分布數據（設計依據）

來源：SudokuWiki 141,672 題分析 + Gordon Royle 17-clue 49,151 題分析

| 累計技法 | 能解決 % 的題目 | 增量 |
|---------|----------------|------|
| Hidden Singles only | 44.6% | — |
| + Pairs/Triples | 69.7% | +25.1% |
| + Locked Candidates | 84.7% | +15.0% |
| + X-Wing | 84.7% | +0.03% |
| + Coloring | 90.7% | +6.0% |
| + XY-Wing | 93.2% | +2.5% |
| + Swordfish | 93.4% | +0.2% |
| + Jellyfish | 93.4% | +0.01% |
| + 全部 Wing 系 | 94.1% | +0.7% |
| 剩餘 ~6% | 需要 AIC / ALS / Forcing Chain 或更高 | |

**結論**：進階技法是自然界的極端稀缺品。我們的定向生成管線（`generate_by_technique.py` + `nirvana_filter.py`）能「逆天改命」，強制產出這些稀有棋盤——**這是技術護城河。**

### 3.4 奇遇演出

當荒野中出現高稀有度題目時，環境會發生質變：

| 稀有度 | 背景變化 | 音效變化 |
|--------|---------|---------|
| 常見 | 正常 | 木質敲擊、紙張翻頁 |
| 稀有（X-Wing 級） | 背景漸變為暗金色調 | 金屬共鳴、遠處鐘聲 |
| 傳說（AIC 級） | 背景轉為深紫 + 粒子飄動 | 低頻震動 + 泛音列展開 |
| 神話（Death Blossom 級） | 全屏靜默 0.3s → 爆發 | 靜默後和弦爆發 |

### 3.5 神獸逃跑與冷卻

若玩家施放失敗，「神獸」逃跑。冷卻以 **題數**（非時間）計算，鼓勵繼續刷題而非關 app 等 timer：

| 稀有度 | 逃跑後冷卻 | 設計意圖 |
|--------|-----------|---------|
| 常見（Pairs/Triples） | 3 題後可再遇 | 快速回歸，鼓勵再試 |
| 稀有（X-Wing, XY-Wing） | 10 題後可再遇 | 有痛感但不絕望 |
| 傳說（AIC, ALS） | 20 題後可再遇 | 「錯過了就要等」的珍惜感 |

## 四、內容架構

### 4.1 秘笈（The Dojo）— 深度修煉

**規格**：40 套技法，每套 25 關，共 1,000 個邏輯節點。

**單一技法的教學流程**：

```
Phase 1: 完整演示 (2s)
  → 電影級動畫展示技法結構與消除過程

Phase 2: 分解步驟
  → 觀察：高亮關鍵格位
  → 判定：解釋為什麼這些格構成該技法
  → 操作：展示消除邏輯

Phase 3: 互動練習 (2-8 題)
  → 玩家實際選取格位、施放招式
  → 即時回饋 + 分級提示（最多 3 級）
```

**秘笈與荒野的橋接**：

```
荒野中施放失敗
  → 神獸逃跑動畫
  → 字幕：「此為【鋒刃】之形... 前往秘笈修煉？」
  → 一鍵跳轉對應教學模組
  → 學完後回到荒野：該技法出沒率 +50%，持續 30 分鐘
```

**設計意圖**：學習不是「補課」，是「開 buff」。

### 4.2 荒野（The Wild）— 隨機狩獵

**機制**：無限刷題，累積 EXP，解鎖更高等級的神獸出沒。

**核心體驗**：

- **常態**：穩定地清除基礎題，磨練手感，累積經驗
- **奇遇**：突然遭遇稀有結構 → 環境質變 → 緊張感升高 → 施放成功 = 巨大成就感
- **失敗**：神獸逃跑 → 學習動機 → 前往秘笈 → 回來更強

### 4.3 邏輯圖鑑（The Bestiary）— 收集驅動

40 種邏輯神獸的圖鑑，記錄玩家的狩獵歷程：

```
┌─────────────────────────────────────────┐
│  ◆ 邏輯圖鑑  (12/40 已發現)               │
├─────────────────────────────────────────┤
│                                         │
│  ✦ 裸單 · Naked Single                  │
│    出沒率: 54%  │ 已狩獵: 342 次          │
│    首次發現: 2026-04-15                   │
│                                         │
│  ✦ 鋒刃 · X-Wing                        │
│    出沒率: 0.8% │ 已狩獵: 7 次            │
│    首次發現: 2026-05-02                   │
│    🏆 最速擊破: 4.2 秒                    │
│                                         │
│  ？？？ (未發現)                           │
│    出沒率: ???                            │
│    「傳說中的邏輯形態，尚未有人目擊...」      │
│                                         │
│  ？？？ (未發現)                           │
│    ...                                  │
└─────────────────────────────────────────┘
```

**設計意圖**：不完整的收集清單自帶強迫症級留存。三個未發現的 ??? 比任何推播通知都有效。

## 附錄 A：設計原則

1. **克制優先**：動畫是證據導向的演出，不是廉價爆閃。每一幀都有邏輯意義。
2. **操作即演出**：玩家的選取過程本身就是動畫的一部分——連線延伸、張力遞增。
3. **失敗即教學**：錯誤回饋永遠指向「你可以去哪裡學」，而非「你做錯了」。
4. **稀缺即價值**：自然分布的統計事實直接成為遊戲內敘事。萬題一遇 = 傳說級。
5. **零干擾原則**：不使用招式的玩家，體驗與現狀完全一致。技能模式預設關閉。
