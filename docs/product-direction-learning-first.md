# 產品方向（Learning-First）

## 一句話定位
把高手直覺拆成可學會、可驗證、可持續進階的數獨系統，先成為「最強學習型數獨產品」。

## 願景階梯
1. 近期目標（現在）
成為最強學習型數獨產品（Learning Product）。
2. 中期目標
成為高階數獨技巧的事實標準（語言、分級、教學流程）。
3. 長期願景
成為「數獨聖經」，推動玩法從「只解題」轉為「可系統化成長」。

## 產品定位
1. 不是一般數獨 App（只給題目）。
2. 不是純教學百科（只有知識，缺少實戰）。
3. 是「教學 + 實戰 + 回放診斷」閉環產品。

## 核心價值主張
1. 學得會：每個技巧有清楚教學與分層練習。
2. 用得出：在實戰中被要求使用並獲得反饋。
3. 看得懂：回放可定位錯誤與關鍵決策。
4. 走得遠：從入門到宗師有連續成長路徑。

## 目標用戶
1. 主力：想從入門進階到高階技巧的玩家。
2. 次力：追求速度、零失誤、對戰與排名的硬核玩家。

## 北極星與核心指標
1. 北極星
每週「完成教學模組 + 通過對應實戰」的人數。
2. 核心指標
- Teach 完成率（模組完成）
- Practice 通過率（首次/重試）
- Replay 使用率（開啟率、回看步數）
- 技巧掌握轉換率（學完後 7 天內在實戰成功使用）
- 留存（D1 / D7 / D30）

## 當前策略（執行原則）
1. 先做可驗證成長，不追求花哨功能。
2. 所有新內容都要可測試、可回放、可量化。
3. 內容擴張必須配合資料治理與 CI 守門。

## 近期里程碑（接續 W6 後）
1. M1：Teach 與 Practice 的掌握度儀表板（可追蹤每個技巧）。
2. M2：Replay 診斷報告（錯誤類型、關鍵轉折、改進建議）。
3. M3：技巧分級標準 v1（對外可引用命名與難度層級）。

## 對外敘事建議
從入門到神人，一條可驗證的數獨進階路徑。
