# W8 Risk Register

## R1 — Ranking logic mismatches user expectations
- Probability: Medium
- Impact: Medium
- Mitigation:
  - Use transparent formula (completion ratio + clears).

## R2 — Alert noise overwhelms users
- Probability: Medium
- Impact: Product quality
- Mitigation:
  - Cap alerts to top N and prioritize actionable items.

## R3 — Key mismatch between UI and i18n
- Probability: Medium
- Impact: Medium
- Mitigation:
  - Normalize learning key names and add fallback guards.
