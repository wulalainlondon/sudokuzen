# W10 Scope Freeze (M2 Phase 2: Diagnosis -> Learning Link)

## Goal
Turn replay diagnosis into an actionable learning route by linking diagnosis focus directly to the Learning dashboard.

## In Scope
1. Extend replay diagnosis payload with learning focus metadata.
2. Add CTA in Replay modal to jump to Stats Learning tab.
3. Add i18n labels for diagnosis-to-learning guidance.

## Out of Scope
1. Backend recommendation engine.
2. Personalized long-term curriculum storage.

## Exit Criteria
1. `npm run check` pass.
2. Replay diagnosis shows learning focus.
3. Clicking CTA opens Stats modal on Learning tab.
