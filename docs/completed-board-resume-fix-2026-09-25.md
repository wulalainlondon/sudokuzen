# 已通關棋盤仍顯示續玩、計時不停 — 2026-09-25

使用者提供 9.18 秒 iPhone PWA 錄影。逐秒檢視後可見關卡「九霄明心」（ID20695）已有三星 1:13 紀錄，大廳卻顯示「繼續遊戲：九霄明心」。點續玩後，棋盤81格全滿，數字鍵均停用；計時由01:16繼續增加，沒有結算畫面。從影片逐格抄錄的81個數字與正式題庫的唯一標準答案完全一致，沒有填錯。證據在 `output/completion-stuck-20260925/`，包含錄影接觸表、代表影格及 `video-board-match.json`。

根因是一般單人 `handleInput` 在最後一格呼叫 `checkWin()` 清除進行中存檔、寫入成績與顯示通關後，函式尾端仍呼叫 `saveGameStatus()`，再次把已解完棋盤寫成續玩存檔。`updateResumeBanner()` 舊邏輯只看存檔 key 是否存在；按續玩只顯示原棋盤並重新開始計時，不再做完成判定。因此錄影的舊版存檔造成滿盤無法操作的畫面。

修正：一般單人及速解的完成棋盤不再寫入進行中存檔；保留練習模式的完成暫存，直到非同步成績落盤。選關畫面讀到舊版已解完存檔且成績已存在時，只移除該殘留存檔，保留星數與時間；若存檔已解完但成績尚未存在，按續玩會透過 `initGame` 的完成判定補做結算。

先新增失敗回歸測試，兩條缺陷皆在修正前重現，修正後通過。隔離 Chromium／WebKit 實際遊戲流程均通過：舊存檔清理保留三星；最後一格通關有結算且秒數停止，存檔不會重建；返回選關後沒有續玩橫幅；未記錄成績的已解棋盤可透過續玩恢復結算。截圖已檢視。完整 69 檔／414 項測試、型別、lint、格式、正式 build/smoke/perf 通過。
